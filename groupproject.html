Group Project Pitch

Verification Drill Down for AI Generated Chart and Image Descriptions

Intended user group

This project is aimed at blind and low vision users who rely on AI generated audio descriptions to understand charts, graphs, and other visual data, whether in a classroom slide, a news article, or a workplace report.

Observation of real users

Adnin and Das (2024) interviewed nineteen blind individuals who use tools like Be My AI, ChatGPT, and Gemini as part of their everyday routines, and found that many participants treat generative AI as an authoritative source of fact rather than a system that can guess wrong, with one participant describing it as the king of knowledge. The same study documented a concrete failure case: Be My AI described a photo and swapped which hand was holding a white cane and which was holding a guide dog's leash, and never identified the dog as a guide dog at all. Since the person asking could not see the photo themselves, they had no independent way to catch either mistake.

What is the Goal

To build a pipeline on top of existing systems. So after a chart or image goes into an existing description generator, the moment a description comes back, it is automatically sent straight to our own evaluation layer before a person ever hears aboy it. Our layer checks the description against the chart's actual data table and flags anything that does not match. Hence, we can run the pipeline across many charts and catch errors automatically, without setting up a live session just to find out whether a given description is accurate.

Skills needed

  • UsingLLM API
  • Enough scripting, likely Python, to build a small pipeline that takes a generated description, checks it against a data source, and flags mismatches
  • Basic data handling to prepare chart datasets with known correct values and seed realistic errors for testing
  • Web development with attention to accessibility tools like screen reader compatible markup and keyboard navigation
  • Experience with text to speech or audio interfaces

Reference

Adnin, R., & Das, M. (2024, October). I look at it as the king of knowledge: How Blind People Use and Understand Generative AI Tools. In Proceedings of the 26th International ACM SIGACCESS Conference on Computers and Accessibility (pp. 1 to 14).
